# Vision

Harz Karreg n'est pas un logiciel de gestion de flotte.

C'est une plateforme d'intelligence logistique.

Notre objectif est de transformer la manière dont les conducteurs, exploitants et dirigeants interagissent avec les données grâce à une expérience moderne, augmentée et centrée sur l'humain.

Chaque interface doit inspirer :

- confiance
- précision
- performance
- innovation
- simplicité

L'utilisateur ne doit jamais avoir l'impression d'utiliser un ERP classique.

Il doit avoir l'impression d'utiliser la plateforme logistique du futur.

---

# Design Philosophy

Le design est guidé par cinq principes.

## 1. Information before decoration

Chaque élément visuel doit avoir une utilité.

Le design ne sert jamais uniquement à être beau.

Il sert à prendre une décision plus rapidement.

---

## 2. Simplicity

Moins de bruit.

Plus d'informations utiles.

Une seule action principale par écran.

---

## 3. Confidence

L'utilisateur doit toujours savoir :

• où il est

• ce qu'il se passe

• ce qui demande son attention

• quelle est la prochaine action

---

## 4. Intelligence

L'interface doit sembler intelligente.

Les données sont contextualisées.

Les recommandations sont expliquées.

L'IA ne fait jamais de magie.

Elle explique toujours pourquoi.

---

## 5. Premium

Harz Karreg est un produit Premium B2B.

Le rendu doit être comparable à :

- Apple
- Linear
- Stripe
- Tesla
- Palantir
- Rivian Fleet

Jamais à un logiciel d'administration des années 2000.

# Visual Language

Le design repose sur :

• grands espaces

• hiérarchie très claire

• gros titres

• peu de couleurs

• cartes bien définies

• animations discrètes

• composants réutilisables

---

# Color Philosophy

Le noir représente :

la technologie

la précision

la concentration

Le vert représente :

l'innovation

la mobilité

l'écologie

l'action

Le blanc représente :

la lisibilité

la simplicité

---

# Typography

Le texte est très hiérarchisé.

Les grands titres sont massifs.

Les paragraphes sont courts.

Les chiffres sont mis en avant.

Toujours favoriser :

- titres très grands
- textes courts
- beaucoup d'espace

---

# Layout

Les interfaces utilisent une grille simple.

Desktop

12 colonnes

Tablet

8 colonnes

Mobile

4 colonnes

Large spacing.

Jamais d'éléments collés.

---

# Navigation

Navigation simple.

Maximum 7 entrées principales.

Exemple :

Dashboard

Fleet

Drivers

Analytics

Marketplace

Notifications

Settings

---

# Cards

Toutes les informations importantes sont placées dans des cartes.

Une carte contient :

• un titre

• une information principale

• une action éventuelle

Jamais plus de trois niveaux hiérarchiques.

---

# Dashboard Philosophy

Le Dashboard répond toujours à quatre questions.

Que se passe-t-il ?

Que dois-je surveiller ?

Que puis-je améliorer ?

Que dois-je faire maintenant ?

---

# Data Visualization

Les graphiques sont simples.

Peu de couleurs.

L'accent est mis sur :

performance

consommation

émissions

activité

trajets

alertes

---

# Artificial Intelligence

L'IA est toujours visible.

Chaque recommandation possède :

• un niveau de confiance

• une explication

• un horodatage

L'utilisateur comprend toujours pourquoi une recommandation est proposée.

---

# Notifications

Les notifications sont classées.

Critical

Warning

Information

Recommendation

Jamais plus de deux notifications critiques visibles simultanément.

---

# Maps

Les cartes sont minimalistes.

Le fond est sombre.

Les routes sont fines.

Les véhicules sont visibles immédiatement.

Les alertes ressortent sans surcharger.

---

# Driver Experience

Le conducteur ne doit jamais être distrait.

Les informations affichées sont limitées.

Toujours privilégier :

navigation

sécurité

écoconduite

alertes

Jamais plus de trois informations critiques simultanément.

---

# Fleet Experience

Le gestionnaire voit :

toute sa flotte

en un coup d'œil.

Les actions les plus importantes sont accessibles en un clic.

---

# Motion Design

Les animations sont discrètes.

Durée :

150 ms

250 ms

400 ms

Uniquement :

Fade

Slide

Scale

Jamais de rebond.

Jamais d'effets spectaculaires.

---
